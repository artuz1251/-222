# Информация о рецептах (Django, SQLite + XML)

Рецепты можно сохранять либо в базу данных SQLite, либо в XML-файл, и просматривать из любого источника.

## Возможности
- Форма добавления: выбор «в БД» или «в XML-файл».
- В БД: проверка на дубликаты (одинаковые название + категория без учёта регистра) - дубликат не добавляется, выводится сообщение.
- Список рецептов: переключатель «Из базы данных» / «Из XML-файлов».
- Для данных из БД: AJAX-поиск по текстовым полям, редактирование (с проверкой значений) и удаление.
- Загрузка XML-файлов с проверкой содержимого.
- Интерфейс на Bootstrap 5 (подключён по CDN).

## Локальный запуск

    python -m venv venv
    venv\Scripts\activate
    pip install -r requirements.txt
    python manage.py migrate
    python manage.py runserver

Сайт: http://127.0.0.1:8000/

## Публикация на хостинге
1. Залить код в GitHub-репозиторий.
2. Создать веб-сервис из репозитория (Netrun / Render / PythonAnywhere и т.п.).
3. Команда сборки: `pip install -r requirements.txt && python manage.py collectstatic --noinput && python manage.py migrate`
4. Команда запуска: `gunicorn config.wsgi` (есть `Procfile`).
5. Переменные окружения: `SECRET_KEY` (любая длинная строка), `DEBUG=0`,
   `CSRF_TRUSTED_ORIGINS=https://ваш-домен` (если форма выдаёт ошибку CSRF).

В папке `examples/` лежат корректный (`test.xml`) и некорректный (`bad.xml`) файлы для проверки загрузки.
XML-файлы сохраняются в папку `recipes_files/` (создаётся автоматически).
